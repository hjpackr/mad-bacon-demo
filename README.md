# Mad Bacon Landscaping

A modern, grass-themed landing page demo for [Mad Bacon Landscaping](https://www.madbacon.com/) in St. Johns, FL.

## Run locally

```bash
npm install
npm run dev
```

Then open the URL Vite prints (usually `http://localhost:5173`).

## Deploy

Production: [https://mad-bacon-demo.vercel.app](https://mad-bacon-demo.vercel.app)

Pushes to `main` deploy to production. Pull requests get a preview URL. That runs through GitHub Actions using the Vercel project `mad-bacon-demo`.
